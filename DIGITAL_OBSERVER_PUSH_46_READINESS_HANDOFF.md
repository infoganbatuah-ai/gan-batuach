# DIGITAL OBSERVER — PUSH 46 READINESS HANDOFF

PUSH 46 is **NOT STARTED**. This document is readiness-only and does not authorize a pilot, customer contact, Production deployment, provider activation, real data processing or implementation work.

## Canonical objective

Run a consented, non-team external Home pilot that proves Profile A direct/zero-install connectivity where technically compatible, remote use, reliability, quality, support and cost. A managed Gateway or team-owned site does not satisfy the zero-install gate.

## Entry gates

- A qualified written legal/privacy decision for the exact Home pilot purpose, jurisdiction, data classes, household roles, notices, camera areas, retention, processors/transfers, incident procedure and withdrawal/deletion flow.
- Owner approval of the named pilot, provider/account use, bounded cost and real-data scope.
- A compatible direct vendor Cloud/API/P2P path with secure enrollment; arbitrary LAN-only RTSP is not a Cloud path.
- Preserved PUSH 38 reliability exceptions and an explicit pilot reliability plan covering Gateway/Connector only where those profiles are actually used.
- PUSH 39 approved notification channels or truthful disabled/pending behavior; no sensitive action automation.
- PUSH 40 entitlement/trial terms and truthful payment state; no unapproved real charge.
- PUSH 44 signed real-device/mobile proof where mobile is part of the pilot.

## Required proof

Record the exact site/profile, agreed duration, consent/notice evidence, camera/system compatibility, remote ingestion/playback, AI path truth, Event/Incident/Evidence access, reconnect/recovery, support log, security incidents, measured bandwidth/storage/inference/provider costs, both canonical cost denominators and pilot exit decision. Separate direct zero-install proof from Software Connector or Managed Edge results.

## Stop conditions

Do not start while external legal approval is pending, while the selected direct path is unverified, or if the owner has not authorized the exact external pilot and cost exposure. Do not infer readiness from PUSH 45 code or internal QA.
