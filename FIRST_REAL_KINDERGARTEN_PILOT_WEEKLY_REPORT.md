## Recommended Fixes

2. Keep parent camera viewing disabled unless legal/privacy approval is documented.
3. Keep observer in shadow mode with human review only.
4. Use test/sandbox provider modes unless live mode is explicitly approved.
5. Review all support issues daily during the first pilot week.
