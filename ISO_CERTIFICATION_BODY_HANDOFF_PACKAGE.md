# ISO Certification Body Handoff Package

Status: readiness package only. This document is not a certification claim.

## Purpose

This package prepares the materials that a certification body may request after consultant review and remediation. The final audit scope, control applicability and certification decision must be determined by the external certification body.

## Proposed Certification Scope

Included:

- Gan Batuach SaaS platform
- Digital Observer Core readiness controls used by Gan Batuach
- Supabase and Vercel deployment architecture
- GitHub CI/CD process
- Internal administration and customer operations dashboards
- Customer data processing governance
- AI governance
- Camera access governance
- Privacy rights workflows

Excluded:

- External providers internal systems
- Customer-owned camera hardware
- External payment processor internal systems
- Future Digital Observer verticals not launched in production

## Statement of Applicability Readiness

The `iso_statement_of_applicability` register should contain for each relevant control:

- Applicable or not applicable decision
- Justification
- Implementation status
- Evidence link or evidence reference
- Control owner
- Review date
- Gap status

This is readiness data only and must be reviewed by the consultant and certification body before being treated as final.

## Audit Limitations

Before audit scheduling, the following external items must be completed:

- ISO consultant gap analysis
- Policy approval review
- Supplier evidence collection
- External penetration test
- Legal/privacy review
- Certification body scope confirmation

## Safe Reviewer Boundaries

Certification reviewers must not receive real child, parent, staff, medical, camera, raw AI, payment or secret material. Evidence exports should contain metadata and control proof only.
