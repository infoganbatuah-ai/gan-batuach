# RELEASE 1 - Internal Demo RC Scope

Date: 2026-06-27

## Purpose

This Internal Demo Release Candidate is intended for controlled stakeholder demonstration with synthetic data only.

Allowed audiences:

- internal testing
- founder review
- investor demo
- partner demo
- controlled stakeholder demo
- synthetic-data walkthrough

Not allowed:

- real kindergarten pilot
- real parents
- real children
- real staff documents
- real payments
- real parent camera viewing
- real AI monitoring
- public App Store / Google Play submission
- production launch

## Included Surfaces

- public website
- app gateway
- login/register demo flow
- role selection
- parent dashboard demo
- kindergarten manager dashboard demo
- staff dashboard demo
- inspector dashboard demo
- admin dashboard demo
- Digital Observer public/demo readiness surfaces
- provider health/readiness pages
- payment readiness/sandbox-only presentation
- camera readiness/gateway status only
- AI observer readiness/shadow state only

## Excluded Capabilities

- live payment charging
- live invoice issuing
- production SMS/WhatsApp/email/push
- parent-facing camera stream
- real RTSP/camera credentials
- raw AI events to parents
- AI accusations or automatic conclusions
- legal/compliance certification claims
- government/regulator status claims

## Recommendation

rc_scope_status = internal_demo_only
