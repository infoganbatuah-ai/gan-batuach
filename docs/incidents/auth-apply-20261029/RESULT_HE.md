# תיקון Auth ובדיקת צפייה HOME_QA — 29.10.2026

אישור בעלים: ״מאשר תיקון Auth ב־HOME_QA בלבד״. הוחל שינוי יחיד ב־Auth: `GOTRUE_EXTERNAL_EMAIL_ENABLED=false -> true`. הרשמה חדשה נשארה חסומה, אישור אימייל נדרש, תמונת Auth קיימת ומוצמדת. נוצר והופעל מחדש Auth בלבד; מזהה וזמן התחלת מסד הנתונים נשארו זהים. לא ניתנה פקודת restart ל־Gateway, Connector או מצלמות; Production ו־main לא שונו.

`application.json` ו־`auth-final.json` מאמתים החלה ובריאות. בקשת stop ראשונה הסתיימה ב־timeout לאחר שהשירות נעצר; השירות המקורי הוחזר מיד (`timeout-recovery.json`), ואז ניסיון מתוקן הסתיים בהצלחה. אין להסתמך על `rolledBack` בקבלה הראשונה לבדה: זו הייתה הנחה שגויה שתוקנה באימות מפורש ובתיקון הכלי. ה־Auth המקורי שמור עצור עם restart policy כבוי. קובץ הגיבוי הפרטי וקונטיינר ה־rollback מפורטים בקבלה; אינם מפורסמים או נכללים ב־Git. rollback מפעיל את הקונטיינר המקורי ומחזיר את מדיניות ההפעלה מהגיבוי לאחר עצירת החדש, ורק לאחר אימות בעלות וזהות; יחזיר גם את חסימת כניסת האימייל ולכן אינו צעד שגרתי.

כניסת סיסמה רגילה דרך Auth הצליחה, `/user` אומת, ללא JWT ידני. 11/11 הרשאות מקור אושרו דרך API המוצר עם מנגנון האבטחה וה־audit הרגילים. API מקומי דחה בקשות תקינות ללא אסימון ועם אסימון שגוי ב־401. לא נבדקה זהות אמיתית של tenant נוסף. אין שינוי roles, מיפוי, סכמה או נתוני מוצר; נוצרו רק רישומי התחברות/צפייה רגילים.

בדיקת HTTP ראשונה העבירה 5/11: ארבעה timeouts ושני מקורות עם פענוח אך בלי התקדמות ברשימה אחרי שלוש שניות. זו דגימה מוגבלת שאינה אבחון שורש. דגימת health מאוחרת יותר דיווחה 10/10 DVR ו־1/1 Tapo מתקדמים, בלי restart מצד כלי זה. היא אינה מוכיחה יציבות ממושכת. נתוני המקורות נשמרים ללא כתובות מדיה, credentials, תמונות או וידאו.

נגן QA זמני על loopback משתמש ב־Auth הרגיל, API הרשאות המוצר ו־Gateway claim. האסימונים נשארים בצד השרת; הדפדפן מקבל נתיבים מקומיים בלבד. הגישה דורשת קובץ nonce פרטי, cookie מסוג HttpOnly ו־SameSite Strict, בדיקת Origin ו־Host ותוקף עד 20 דקות. כשל bootstrap קודם נבע מ־Referrer-Policy ששלח Origin null בטופס: הוגדר same-origin בלי לרכך בדיקת Origin. זה נגן smoke ייעודי ואינו הוכחה למסך המוצר הקנוני או לאתר הענן.

תוצאה סופית: 11/11 המקורות עברו בנגן הבדיקה המקומי בדפדפן Chrome: DVR ערוצים 1–8,10,11 ו־Tapo. ההתקדמות הייתה 5.871–8.138 שניות ו־128–208 תמונות מפוענחות למקור. התוצאה מתועדת ב־`player-third-results.json` ואומתה גם בממשק הדפדפן. לכל מקור נדרשים ממדים חיוביים, יותר משנייה של התקדמות ותמונות מפוענחות בשמונה שניות צפייה. בדיקה יחידה אינה soak, AI או הוכחת Production.

שש בדיקות גבולות לכלי ההחלה וארבע לנגן עברו. בדיקות התחביר של כלי Python עברו. helper היציאה תוקן להסרת קובץ הגישה לצד הסשן; כשל ניקוי תיקייה קודם התרחש אחרי logout מוצלח, והניקוי הושלם בנפרד. קבלות היציאה מתעדות את מצב הסשנים.

הענף `codex/stream-recovery-diagnostics-20261029`; שינוי תצורת הקוד הקודם ב־`3ff269e2`. הקוד והראיות הם QA בלבד. אין ספק או תשלום חדש; אין טענה לתקרת העלות הכוללת ללא נתוני ספקים. שימור מרוחק ואינטגרציה טרם אומתו. בדיקת נגן המוצר הקנוני ויציבות ממושכת נשארות עבודה נפרדת אם אינן מתועדות כהצלחה מפורשת. ההעברה לצ׳אט אחר לא בוצעה משום שבדיקת האישור האוטומטית דחתה מסירה קודמת; לא בוצעה עקיפה.

כל שלושת הסשנים הזמניים נסגרו ביציאה רגילה מקומית. בסשן האחרון `logoutPassed: true`; קובץ הסשן וקובץ הגישה הוסרו והפורט 52577 סגור. כרטיסיית הבדיקה נסגרה. תיקון Auth נשאר פעיל כמאושר; לא הושאר שרת viewer או סשן בדיקה פעיל. השידור עבר בדיקת דפדפן מקומית מלאה, אך טענת חזרה במסך המוצר הקנוני ובענן עדיין אינה מוכחת.
