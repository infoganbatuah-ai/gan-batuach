# Pilot Success Metrics

Track these metrics during the first real kindergarten pilot. Review daily during week one and weekly after stabilization.

## Pilot Activation

Active accounts:

- Admin account active: yes/no
- Manager/owner active: count
- Staff active: count
- Parents active: count
- Inspector active: count

Onboarding:

- Parents invited
- Parents logged in at least once
- Children created
- Children pending parent completion
- Children pending manager approval
- Active children
- Completed child onboarding percentage

Suggested target for pilot week one:

- 1 manager active
- at least 1 staff active
- at least 5 parents invited
- at least 3 parents logged in
- at least 3 active children

## Daily Operations

Track:

- Attendance updates completed
- Meal updates completed
- Sleep updates completed
- Mood updates completed
- Incidents created
- Incidents resolved
- Parent requests opened
- Parent requests handled
- Staff tasks completed

Suggested targets:

- 80%+ active children receive a daily journal update.
- Parent requests receive first response within one working day.
- No incident remains open without owner for more than 24 hours.

## Parent Experience

Track:

- Parent dashboard visits
- Parent requests sent
- Parent requests answered
- Document uploads completed
- Camera page visits if cameras are included
- Failed parent login attempts
- Support tickets from parents

Success signals:

- Parents understand child status without calling the manager.
- Parents do not submit duplicate child profiles.
- Parents do not ask where to complete registration.

## Manager Experience

Track:

- Leads handled
- Children approved
- Payments marked paid/failed/not transferred
- Open requests
- Open incidents
- Open smart insights
- End-of-day checklist completion
- Finance page load issues

Success signals:

- Manager starts day from dashboard command center.
- Manager handles urgent items without searching.
- Completed actions disappear from pending lists.

## Staff Experience

Track:

- Staff logins
- Child updates by staff
- Staff tasks completed
- Staff incidents reported
- Staff document uploads

Success signals:

- Staff can update child status in under 10 seconds.
- Staff dashboard does not require admin/finance knowledge.

## Inspector / Admin Experience

Track:

- Inspector assigned kindergartens
- Inspections scheduled
- Inspections completed
- Violations opened
- Violations resolved
- Admin support actions completed

## Reliability

Track:

- System uptime
- `/api/health` status
- `/api/health/deep` status
- Build/deploy incidents
- Global error page reports
- Failed uploads
- Failed auth/login attempts
- Failed critical mutations

Suggested targets:

- No unresolved critical security issue.
- No global crash in pilot daily flow.
- Health route remains OK during operating hours.

## Open Work Queue

Track current count:

- Unresolved incidents
- Unresolved parent requests
- Children pending approval
- Parents pending child completion
- Failed/not transferred payments
- Missing documents
- Camera issues
- Staff missing documents

## Weekly Pilot Review

Answer:

- What did the manager use every day?
- What did staff use every day?
- What did parents understand without support?
- Which flow caused the most support tickets?
- Which action still takes too many clicks?
- Did any user see data they should not see?
- Did the system remove work from the manager?

## Pilot Exit Criteria

Ready to expand when:

- Manager uses dashboard daily.
- Staff can update children without support.
- Parent onboarding completion is above 80% for invited parents.
- No critical privacy/security issue remains open.
- No major dashboard has repeat global crashes.
- Support playbook covers recurring issues.
- First kindergarten confirms the system saves time or improves clarity.
