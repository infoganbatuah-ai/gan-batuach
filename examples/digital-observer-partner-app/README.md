# Independent partner application

This sample imports only `@digital-observer/sdk` public surfaces. Server code keeps the rotating `dosvc_` credential outside the browser. Embedded browser code receives only a short-lived `doemb_` token restricted to one partner customer, Site, audience, origin and scope.

The Development sample proves contract conformance and cross-customer denial with synthetic data. It does not prove a real OEM partner, vendor camera/VMS, Production domain, payment provider, external SSO or zero-install deployment.
