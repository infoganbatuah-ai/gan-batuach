# PILOT FIX 1 - Real Pilot Minimum Scope

Date: 2026-06-27

## Smallest Safe Real Pilot

Recommended first real pilot scope:

- one real kindergarten
- one kindergarten manager
- one platform admin
- one or two staff users
- one inspector or test inspector
- very limited parent users only after RLS/legal/consent approval
- manual or sandbox subscription/payment state
- no live parent camera viewing
- no raw AI to parents
- AI shadow mode only if legal/security approved
- camera internal/admin/manager-only only if camera policy/gateway/audit approved

## Allowed In First Pilot After Gates Pass

- real manager account
- real kindergarten profile
- limited real staff accounts
- limited inspector workflow
- controlled enrollment flow
- in-app notifications
- manual/sandbox payment status
- inspections and reports if privacy/storage checks pass

## Excluded From First Real Pilot

- public parent onboarding at scale
- public store launch
- automatic AI alerts
- AI accusations or conclusions
- parent live camera viewing unless fully approved
- live payment automation unless provider verified
- official regulatory/government claim
- real-time abuse/violence detection claim
- external bulk notifications

## Data Rule

Synthetic/demo data must remain separate from real pilot data.
