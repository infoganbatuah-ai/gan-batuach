`GB_M31_EXTERNAL_DELIVERY_ENABLED` and `GB_M31_DELIVERY_WORKER_SECRET` are not set by this change. The worker has no scheduler and cannot send in the isolated Development setup. `provider_submission_available` means only that an enabled adapter may submit to a provider; it never means delivered. In-app notifications continue through GB-M30 irrespective of external availability.

The new receipt table stores only verified provider event ID, normalized state and linked delivery-log ID. It intentionally stores no raw webhook payload, destination, OTP, message text or credential. Automatic deletion is withheld pending approved financial/security retention policy; expected volume is one row per relevant provider event, indexed by delivery log and deduped by provider/event ID.
