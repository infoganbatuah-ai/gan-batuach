## Authorization and scope

A trusted operator must independently identify a confirmed Development Observer account, its active Product session, one immutable submission, its expected fixture label, one synthetic source ID, one trial package and a short deadline. The source represents metadata only. It has no stream, provider credentials, monitoring or dispatch. On the canonical schema its Site reference is required; deleting a Site can cascade to camera sources. Never use a cascading Site deletion as rollback. The canonical account lock serializes competing requests for the same owner. A committed retry must check both sides of the pair and the qualification pin before returning their identifiers.
