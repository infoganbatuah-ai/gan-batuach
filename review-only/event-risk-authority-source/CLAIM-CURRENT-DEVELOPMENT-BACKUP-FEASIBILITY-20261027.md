## Decision

**Backup size preflight: plausible, not proven.** The measured three-DB physical total plus aggregate Storage allocation is far below the 1 GiB *proposed* encrypted-file ceiling, but no dump has been made and compression/encryption output size is not bounded by these measurements alone. Recheck free space and impose an actual write cap before any later authorized capture. The older 2026-10-22 logical backup still predates the 30th post-baseline migration; this measurement is not a replacement recovery copy.

**Isolated encrypted restore: BLOCKED / unqualified.** The cached PostgreSQL 17.6 image and large Kingston headroom help, but the encrypted volume, isolated server boundary and offline mount path have not been constructed or tested. A future operation must prove those controls without using the original DB volume or plaintext restore on `noowners` storage. If that cannot be done using existing local resources within the approved scope, obtain a separate suitable destination or explicit bounded provider/cost approval; do not relax isolation.

No new owner approval is requested by this metadata-only receipt.
