# Owner-held age identity: local no-echo input gate

**2026-10-28, preparation only.** The previous one-shot `pbpaste` check returned `EMPTY`, not `NO_MATCH`; the owner's actual recovery identity was **not** tested here. No capture, decrypt of a real artifact, restore, service, database, provider or Git remote action occurred.

`owner-age-tty-verify.py` is an owner-run Mac Terminal tool. It reads one line from the process's own terminal stdin, never from Codex tools or the clipboard API. It disables `ECHO` and `ECHONL` before prompting, verifies the no-echo state, accepts at most 256 bytes within two minutes, flushes excess pending input, and restores the previous terminal settings in `finally`, including handled `SIGINT`, `SIGTERM`, `SIGHUP`, `SIGQUIT` and `SIGTSTP`. `SIGKILL`, power loss and terminal failure cannot be caught; the owner should reopen Terminal or run `stty echo` if a terminal remains silent after such a failure. A private key is never supplied as an argument, environment variable, file or shell command. A direct Terminal paste may still temporarily use the owner's local clipboard; the tool itself does not read or log it, and the owner should replace clipboard contents afterward.

The tool checks the local **public** recipient against pinned SHA-256 `1fc9645eff132753e75a26eb0856b6f9abe0a26af6002625346832a8a89d97b4` before prompting. It pipes the private line to the installed `age-keygen -y`, checks only the derived public recipient digest, suppresses age stderr, and emits only `MATCH`, `NO_MATCH`, `EMPTY` or `UNAVAILABLE`. It disables core dumps for its process and scrubs its mutable key buffer. Python and child-process runtimes cannot promise erasure of every transient immutable memory copy; no persistent plaintext key is intentionally created. It writes only result, UTC time and public digest to `/private/tmp/do-age-owner-key-check-20261028.json` with exclusive creation and mode `0600`. It refuses an existing receipt rather than overwriting evidence.

Synthetic-only tests cover genuine age key derivation, incorrect digest and malformed key rejection; a pseudo-terminal verifies no echo and exact termios restoration on normal input, oversize input and a handled signal; receipt content/mode/exclusive creation is checked. A non-TTY invocation fails closed. These tests are not owner-key evidence.
