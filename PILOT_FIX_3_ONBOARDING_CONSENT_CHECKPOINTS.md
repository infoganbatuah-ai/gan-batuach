# PILOT FIX 3 - Onboarding Consent Checkpoints

Date: 2026-06-28

## Consent Map

| Checkpoint | Required linked documents | Suggested checkbox wording | Mandatory | Separate consent | Legal review |
| --- | --- | --- | --- | --- | --- |
| Registration role selection | Terms, Privacy | קראתי ואני מסכים/ה לתנאי השימוש ומדיניות הפרטיות | yes before real users | no | required |
| Parent registration | Terms, Privacy, Child Data, Parent Consent | אני מאשר/ת שאני הורה/אפוטרופוס מוסמך ומסכים/ה לעיבוד המידע לפי המסמכים | yes | yes for child authority | required |
| Child profile creation | Child Data, Parent Consent, Data Retention | אני מאשר/ת יצירת פרופיל ילד ושיתוף מידע רלוונטי עם הגן הנבחר | yes | yes | required |
| Enrollment request | Privacy, Child Data, Parent Consent | אני מאשר/ת להעביר את פרטי הבקשה והילד לגן הנבחר | yes | yes | required |
| Manager registration | Terms, Privacy, Manager Pilot Terms, Payments | אני מאשרת שאני מוסמכת מטעם הגן ושאקבל הסכמות נדרשות | yes | yes | required |
| Manager onboarding | Manager Pilot Terms, Camera, AI, Payments | אני מאשרת אחריות למדיניות גן, הסכמות, מצלמות/AI ותשלומים לפי ההגדרות | yes for pilot | separate camera/AI/payment | required |
| Staff registration/application | Terms, Privacy, Staff Notice | קראתי את הודעת הצוות ומסכים/ה לשימוש במידע לצורכי עבודה | yes | documents if uploaded | required |
| Inspector registration | Terms, Privacy, Inspector Notice | קראתי את הודעת המפקח ומתחייב/ת לסודיות וגישה לפי שיוך בלבד | yes | evidence upload if used | required |
| Camera activation | Camera Notice, Parent Consent, Manager Pilot Terms | אני מאשרת שמדיניות מצלמות, הודעות והסכמות נבדקו לפני הפעלה | yes if camera enabled | yes | required |
| Parent camera viewing | Camera Notice, Parent Consent | אני מבין/ה שצפייה כפופה למדיניות, נוכחות הילד, שעות וטוקן זמני | yes if enabled | yes | required |
| AI/observer activation | AI Notice, Manager Pilot Terms, DPIA/legal review | אני מאשרת ש-AI יפעל רק במצב שאושר, עם review אנושי וללא raw AI להורים | yes if AI enabled | yes | required |
| Payment/subscription | Payment Terms, Terms | אני מאשרת את תנאי המנוי/דמו/חיוב | yes if paid | no | legal/accounting required |
